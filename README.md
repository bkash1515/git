# git# Taller Git

## Descripción

Este proyecto fue realizado como parte del taller práctico **"Dominando Git y GitHub desde Cero"**.

El objetivo es aprender a utilizar Git para controlar versiones de un proyecto y GitHub para almacenar y compartir el código de manera remota.

## Tecnologías utilizadas

- HTML5
- CSS3
- Git
- GitHub

## Archivos del proyecto

- `index.html` — Página principal del proyecto.
- `estilos.css` — Hoja de estilos utilizada para darle formato a la página.
- `.gitignore` — Archivo utilizado para indicar qué archivos no deben ser incluidos en el repositorio.
- `.env` — Archivo con datos ficticios que es ignorado por Git.

## Objetivos del taller

Durante el desarrollo del taller se practicaron:

- Configuración inicial de Git.
- Creación de un repositorio local.
- Uso de `git status`.
- Uso del área de preparación (staging).
- Creación de commits.
- Uso de `.gitignore`.
- Creación y administración de ramas.
- Uso de `git merge`.
- Conexión de un repositorio local con GitHub.
- Publicación del proyecto mediante `git push`.
